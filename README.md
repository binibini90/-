# 자기소개서 
 ## 1. 자기소개   
 
  저는 반도체디스플레이 전공으로 입학했지만, 코딩 수업에서 코드 한 줄에 결과가 바로 바뀌는 게 너무 재밌어서 콘텐츠IT로 전과했습니다. 그러다 머신러닝 수업에서 Gradient Descent를 처음 배웠는데, 손실 함수를 줄여가며 Local  Minima를 빠져나가는 과정이 퍼즐 푸는 것 같아서 빠져들었습니다. 그때 AI를 제대로 파보자고 결심했습니다.
 혼자 공부하는 것도 좋지만 팀 경험을 더 쌓고 싶어서 SK Networks Family AI Camp에 참여했습니다. 전기차 분석, Netflix 이탈 예측, 창업 지원 챗봇 등 5개 프로젝트를 하면서 매번 새로운 기술을 익혔고, 마지막 프로젝트에서는  팀장을 맡아 특허 FTO 분석 AI FTOGuard를 만들었습니다. sLLM 파인튜닝부터 백엔드, AWS 인프라까지 직접 구축했고, 우수 프로젝트로 선정됐습니다.

  ## 2. 성격의 장단점                                                        
                                                                          
 팀 프로젝트에서 팀장을 맡으며, 감정적인 충돌 없이 효율적으로 협업하는 방식을 고민해왔습니다.

프로젝트 진행 중, 한 팀원의 발언이 길어져 회의가 지연되고 다른 팀원들이 어려움을 겪는 상황이 발생했습니다. 즉각적인 피드백이 감정적 상처로 이어질 수 있다고 판단하여, 개인을 지적하기보다는 발언 권한을 가질 수 있는 봉과 아젠다 중심의 회의 룰이라는 구조적 규칙을 도입했습니다. 덕분에 분위기를 해치지 않으면서도 회의 효율성을 20% 이상 높이고, 회의가 본래 목적대로 진행되도록 체계를 잡았습니다.

또한, 기술적 난이도로 인해 프로젝트 참여에 어려움을 겪는 팀원을 위해, 업무를 작은 단위로 쪼개고 가이드를 제공하며 점진적으로 몰입할 수 있도록 도왔습니다. 이 과정에서 구성원의 성향에 맞춘 가시적인 로드맵을 제시하는 것이 팀 전체의 성과로 이어진다는 것을 배웠습니다.
다만, 상대방의 입장을 지나치게 고려하다가 때로는 피드백 타이밍을 놓칠 뻔한 경험이 있습니다. 이를 개선하기 위해, 업무상의 피드백은 감정이 아닌 데이터와 사실을 기반으로 즉시 나누되, 전달 방식은 상대방이 수용하기 편한 언어로 조율하는 훈련을 지속하며 프로페셔널한 커뮤니케이션 역량을 키워나가고 있습니다.

## 3. 지원동기 

 AI가 실제 현장의 문제를 푸는 데 기여하고 싶어서 AI 개발자를 지원합니다.                                           

부트캠프에서 특허 FTO 분석 AI를 만들면서, 원래 며칠씩 걸리던 작업을 AI로 단축할 수 있다는 걸 직접 경험했습니다.
2만여 건 데이터로 sLLM을 파인튜닝해서 94% 정확도를 냈고, 같은 크기 Base 모델보다 46%p 높은 성능이 나왔습니다.
도메인에 맞게 잘 학습시키면 작은 모델로도 충분히 실무에 쓸 수 있다는 걸 느꼈습니다.                               
                                                                                                                    
저는 7.8만 건 특허 문서를 하이브리드 검색으로 인덱싱하고, vLLM으로 파인튜닝된 모델을 서빙하여 실제 서비스에 연동한 경험이 있습니다. 특히 특허-청구항-구성요소 간의 관계형 데이터 구조를 설계하며, 비정형 데이터를 체계적으로 구조화하는 경험을 쌓았습니다.                                                                                     
RAG 파이프라인 설계부터 FastAPI 백엔드 개발까지 해본 경험을 살려서, 지식 기반 AI 시스템 개발에 기여하고 싶습니다.

## 4. 입사 후 포부 

[가장 빠른 적응력과 전문성으로, 신뢰할 수 있는 AI 시스템을 만들겠습니다]  

입사 후 먼저 회사의 기술 스택과 서비스 아키텍처를 빠르게 파악하는 데 집중하겠습니다. 저는 부트캠프 당시 6개월이라는 짧은 기간 동안 sLLM 파인튜닝, RAG, 백엔드, 클라우드 등 폭넓은 기술을 체득하여 성공적으로 프로젝트를 완수하고 수상까지 거둔 경험이 있습니다.
이러한 압축적인 학습과 실행 베이스가 있기 때문에, 새로운 비즈니스 환경과 낯선 기술 스택에도 빠르게 적응할 수 있습니다.                                                                                                         

적응 이후에는 데이터 구조화와 지식 체계 설계 역량을 더해, LLM/RAG 파이프라인과 결합한 지식 기반 AI 시스템을 고도화하고 싶습니다. FTOGuard에서 특허 데이터의 관계 구조를 설계한 경험을 바탕으로, 온톨로지와 지식그래프 기술을 빠르게 습득하여 실무에 기여하겠습니다.
